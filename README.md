# Blinkit SQL Data Analysis

## 📌 Project Overview

This project analyzes Blinkit sales data using SQL to identify key business insights and sales trends.

## 🛠️ Tools Used

* SQL
* MySQL
* GitHub

## 🔍 Analysis Performed

* Total and average sales analysis
* Sales by product category
* Sales by outlet type and size
* Outlet location analysis
* Customer rating analysis
* Top-performing products/categories

## 📊 Key Insights

The analysis helps understand sales performance, product trends, and outlet performance using SQL queries.

## 📂 Files

* `Blinkit_SQL_Project.sql` – SQL queries used for the analysis
* `Blinkit_Data.csv` – Dataset used for the project
